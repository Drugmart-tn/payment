# PIR Activation — Fritzing project

This folder contains a Fritzing-compatible project bundle for a PIR-activated buzzer prototype.

Files included:
- pir-activation.fzp — minimal Fritzing project XML (placeholder)
- breadboard.svg — breadboard view (placeholder SVG)
- schematic.svg — schematic view (placeholder SVG)
- pcb.svg — PCB view (placeholder SVG)
- README.md — wiring, parts list, and instructions to create a .fzz package

Notes
- These are text/SVG placeholders created in this environment (Fritzing desktop not available here). To create a .fzz package you can zip these files into a single archive and rename it to pir-activation.fzz (or pir-activation.fzz.zip) and open it in Fritzing on your machine.
